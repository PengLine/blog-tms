模块由 7 个平铺的 HTML 单页组成，每个文件自包含 `<style>` + `<body>` + `<script>`，无后端路由或构建产物。
- 统一布局：所有页面共享相同的 header（logo + `#current-username` + 退出按钮）+ sidebar（固定 250px 宽，列出 7 个功能入口）+ content 主区域结构，通过 `.active` 类标记当前页。
- 导航入口集中在 `transporter-index.html` 的侧边栏中，以相对路径链接到其他同目录 HTML 文件，形成扁平的多页 SPA 式导航。
- 业务逻辑按页面拆分：index 负责统计卡片与今日任务；departure 实现发车前检查清单、表单提交与历史记录表；schedule 内置日/周/月三种日历视图；clock/performance/route/loading 各自承载对应业务。
- 数据层完全基于 `localStorage`，键名采用 `transporter*` 前缀（如 `transporterTasks_${today}`、`transporterStats_${today}`、`transporterDepartureHistory`、`transportSchedules`），跨页面通过同一 key 共享状态。
- 公共能力（登录校验、用户信息展示、登出）通过外部 `common.js` 暴露的 `checkLoginStatus('transporter')`、`displayCurrentUser()`、`logout()` 调用，本模块不重复实现认证逻辑。
- 样式全部内联在 `<style>` 标签中，使用 CSS 变量风格的颜色（`#f9ca24` 为主色、`#ff6b6b` 为危险色），并通过 `@media (max-width: 768px)` 做移动端适配。
