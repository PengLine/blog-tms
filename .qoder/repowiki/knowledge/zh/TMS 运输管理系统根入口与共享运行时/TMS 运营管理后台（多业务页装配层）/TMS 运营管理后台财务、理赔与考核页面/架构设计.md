三个并列的单文件 HTML 页面（tms-finance.html / tms-claim.html / tms-evaluation.html），每个页面自包含完整布局骨架：顶部 header + 左侧 sidebar（含运营功能子菜单）+ 右侧 content 区域。

- 运行时依赖统一通过 `<script src="common.js">`、`tms-store.js`、`tms-ui.js`、`tms-pages.js` 引入；页面在 `DOMContentLoaded` 中调用 `checkLoginStatus('admin')` 校验管理员身份后执行 `TmsUI.initShell()`，再委托 `TmsPages.render('finance'|'claim'|'evaluation', ...)` 渲染内容区。
- 业务数据全部使用 `localStorage` 持久化，key 分别为 `tmsFinanceRecords`、`tmsClaims`、`tmsEvaluations`；首次加载由各自的 `initMock*` 函数写入硬编码模拟数据，随后 `renderXxx()` 将列表渲染到对应容器。
- 用户交互操作以 `window.xxx = function(id) { ... }` 形式挂载到全局，供模板字符串中的内联 `onclick="xxx('${id}')"` 直接调用，修改后重新 `localStorage.setItem` 并刷新列表。
- 页面间通过侧边栏 `<a href="tms-*.html">` 互相跳转，并在同级菜单项上保持 `active` 高亮标记；模块之间无 JS 级耦合，仅通过导航链接形成关系。
- 理赔记录与财务记录通过 `claimId`/`orderId` 字段做语义关联，但代码层面未实现跨表查询。
