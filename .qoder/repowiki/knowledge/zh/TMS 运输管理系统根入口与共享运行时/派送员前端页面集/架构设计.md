本模块由 8 个独立的单页 HTML 文件组成，每个文件对应一个派送员功能入口（deliveryman-index.html 为导航入口，其余按 tasks/collection/clock/performance/contacts/exception/areas 划分）。所有页面共享同一套布局骨架：顶部 header + 左侧 sidebar 导航 + 右侧 content 区域，并通过相对链接互相跳转。业务数据不依赖后端 API，而是通过 `localStorage` 中的 key（如 `deliverymanTasks`、`deliverymanClockRecords`、`deliverymanExceptions`）进行持久化；首次访问时由各自页面的 `initializeXxxData()` 函数生成模拟数据并写入 localStorage。登录态与用户信息统一复用根目录的 `common.js`（通过 `<script src="common.js">` 引入），调用 `checkLoginStatus('deliveryman')`、`displayCurrentUser()`、`logout()` 等公共方法。页面之间通过 URL query string 传递上下文（例如 `deliveryman-tasks.html` 跳转到 `deliveryman-exception.html?taskId=...`），不存在组件化或模块化 JS 框架。
