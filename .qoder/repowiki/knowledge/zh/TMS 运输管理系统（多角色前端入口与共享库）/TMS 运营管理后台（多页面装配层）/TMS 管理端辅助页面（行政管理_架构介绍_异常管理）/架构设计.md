本模块由三个相互独立的 HTML 单页组成，均遵循同一加载与渲染约定：
- 统一入口模式：每个页面在 `DOMContentLoaded` 中调用 `checkLoginStatus('admin')` 校验管理员角色，随后通过 `TmsUI.initShell()` 初始化顶部/侧边栏外壳，再调用 `TmsPages.render('<pageKey>', container)` 将业务内容注入 `.content` 区域。
- 共享依赖：通过 `<script src="common.js">`、`tms-store.js`、`tms-ui.js`、`tms-pages.js` 以及样式 `tms-ui.css?v=20261022d` 复用登录态、存储与 UI 壳逻辑，页面自身只负责各自业务片段。
- 数据层：`tms-administration.html` 使用 `localStorage` 中的 `tmsAdminRecords` 键维护会议/通知/文档三类行政记录；`tms-exception.html` 以硬编码表格展示异常样例，无持久化逻辑。
- 导航结构：`tms-administration.html` 与 `tms-exception.html` 内置完整侧边栏菜单，包含「运营管理」二级子菜单（派送地址、签收率、入库扫描率等），并通过全局函数 `switchTab` / `scrollToSection` 配合 `data-legacy="1"` 的 `<script type="text/plain">` 块实现纯 CSS 子菜单展开与统计区块滚动。
- `tms-architecture.html` 是纯展示型文档页，不依赖 shell 渲染，仅通过 CSS 变量与动画绘制架构图、网络拓扑图与服务集群节点。
