三个并列的独立 HTML 单页（tms-hr.html / tms-user.html / tms-vehicle.html），共享同一套布局骨架：顶部 header + 左侧 sidebar 导航 + 右侧 content 区域，并通过 `common.js` 提供的 `checkLoginStatus('admin')` 做管理员鉴权，再调用 `TmsUI.initShell()` 渲染统一外壳。

- tms-hr.html：基于 `localStorage` 中的 `tmsEmployees` 模拟数据，使用内联脚本实现员工列表渲染、启用/停用切换；同时通过 `TmsPages.render('hr', ...)` 接入公共页面路由。
- tms-user.html：采用声明式配置驱动——通过 `TmsUI.table` 和 `TmsUI.formModal` 以对象字面量定义 users / roles / permissions / departments 四个 tab 的列、搜索、筛选、工具栏与表单字段，所有读写走 `TmsStore` 持久层，并通过 `TmsStore.subscribe(renderUserKpis)` 实现 KPI 联动刷新。
- tms-vehicle.html：纯静态占位页面，表格为硬编码 HTML 行，仅挂载 `TmsPages.render('vehicle', ...)` 路由入口，业务逻辑在 `tms-pages.js` 中实现。

依赖方向：页面 → common.js（登录/退出）→ tms-store.js（CRUD）、tms-ui.js（通用 UI 组件）、tms-pages.js（页面路由），不互相引用。
