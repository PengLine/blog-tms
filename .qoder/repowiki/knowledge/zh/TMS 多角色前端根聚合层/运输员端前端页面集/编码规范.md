- 每个页面在 `DOMContentLoaded` 中先调用 `checkLoginStatus('transporter')` 校验角色，再绑定退出按钮并调用 `displayCurrentUser()` 渲染用户名。
- 页面间通过相对路径互相链接（如 `href="transporter-departure.html"`），并在侧边栏 `<a>` 上切换 `class="active"` 高亮当前页。
- 本地存储键统一以 `transporter` 为前缀并按日期维度组织（如 `transporterTasks_${today}`、`transporterStats_${today}`、`transporterPerformance_${year}_${month}`）。
- UI 状态值使用统一的三段枚举 `pending` / `in-progress` / `completed`，并以对应的 CSS class 控制颜色显示。
- 页面模板使用内联 `<style>` 块定义，包含基础重置、header/sidebar/content 三栏布局以及 `@media (max-width: 768px)` 响应式断点。
