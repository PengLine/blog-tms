三个并列的 HTML 页面文件，各自包含内嵌 CSS + JS，共享同一套运行时依赖：
- 公共层：`common.js`（登录校验 `checkLoginStatus`、`logout`、`getCurrentUser`）、`tms-store.js`（基于 localStorage 的实体 CRUD 与 `dailyStats`/`overview` 聚合查询）、`tms-ui.js`（`table`/`chart`/`formModal`/`detailGrid`/`kpis` 等 UI 组件）。
- 页面层：`tms-operation.html` 是核心业务页，通过 `OP_TABLES` 数组注册多个 `U.table` 实例（派送地址、运营日报、签收率/入库/出库/派送扫描率、漏拣、叉车货、考核指标、考核记录、改单记录），并订阅 `TmsStore.subscribe(renderOperation)` 实现数据刷新；`tms-performance.html` 与 `tms-timing.html` 则通过 `TmsPages.render('performance'|'timing', ...)` 走统一页面渲染管线，同时各自保留一段 `<script type="text/plain" data-legacy="1">` 包裹的旧版逻辑（localStorage 模拟数据 + alert）。所有页面均通过侧边栏 `<nav id="admin-nav">` 互链，形成扁平的多页 SPA 导航结构。
