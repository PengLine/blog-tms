- 页面统一采用「header + sidebar + content」三段式布局，侧边栏使用 has-submenu/submenu 结构承载二级菜单，当前页 a 标签加 active 类高亮。
- DOM 就绪后的启动流程固定为：先 checkLoginStatus('admin')，再 TmsUI.initShell()，最后 TmsPages.render(页面标识, '.content')。
- 业务交互代码放在 `<script type="text/plain" data-legacy="1">` 块中，与上方启动脚本分离，便于后续迁移。
- 表格行操作按钮统一使用 action-btn.view / start / complete / resolve / cancel 等语义化 class，配合外层 transport-table / sorting-table / loading-table 命名空间。
- 状态标签统一以 status 后缀类名区分（如 transport-status.shipping、sorting-status.pending、loading-type.loading），颜色通过 CSS 类映射。
