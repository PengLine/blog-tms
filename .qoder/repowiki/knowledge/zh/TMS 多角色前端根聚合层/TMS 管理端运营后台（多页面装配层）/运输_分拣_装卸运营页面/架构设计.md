三个并列的独立 HTML 单页（tms-transport.html / tms-sorting.html / tms-loading.html），共享同一套布局骨架：顶部 header + 左侧 sidebar（含“运营功能”导航及“运营管理”子菜单）+ 右侧 .content 主区域。每个页面在 DOMContentLoaded 中调用 `checkLoginStatus('admin')` 校验权限后，通过 `TmsUI.initShell()` 初始化外壳并调用 `TmsPages.render('<transport|sorting|loading>', ...)` 将业务视图注入 `.content`；实际渲染逻辑由外部 `tms-pages.js` 承担，本模块仅负责骨架与占位数据。样式以 `<style>` 内联为主，并通过 `<link href="tms-ui.css?v=20261022d">` 引入全局 UI 样式；脚本依赖顺序固定为 common.js → tms-store.js → tms-ui.js → tms-pages.js。页面内的表格与统计卡片均为硬编码静态数据，按钮事件目前仅用 alert 占位，尚未接入后端 API。
