三个独立 HTML 单页（tms-material.html / tms-warehouse.html / tms-capacity.html），共享同一套 Shell 布局：顶部 header + 左侧 sidebar 导航 + 右侧 .content 主区域，侧边栏通过 `<a href="tms-*.html">` 互相链接并标记 `.active` 高亮当前页。

- 运行时依赖统一在 `<head>` 中引入 `tms-ui.css?v=20261022d`、`common.js`、`tms-store.js`、`tms-ui.js`、`tms-pages.js`，页面初始化脚本调用 `checkLoginStatus('admin')` → `TmsUI.initShell()` → `TmsPages.render('<material|warehouse|capacity>', ...)` 完成壳渲染与内容注入。
- 业务数据层：tms-material.html 使用 localStorage 键 `tmsMaterials` 维护模拟物资数据（含 in_stock / low_stock / out_of_stock 状态机），并提供采购、更新库存、查看详情等 window 全局函数；tms-warehouse.html 与 tms-capacity.html 目前仅展示静态表格行，操作按钮为 alert 占位。
- 样式全部内联于各文件 `<style>` 块，包含响应式 @media (max-width:768px) 适配与 has-submenu 子菜单展开逻辑。
- 依赖方向单向：页面 → common/tms-store/tms-ui/tms-pages 公共库，无跨页面 JS 引用。
