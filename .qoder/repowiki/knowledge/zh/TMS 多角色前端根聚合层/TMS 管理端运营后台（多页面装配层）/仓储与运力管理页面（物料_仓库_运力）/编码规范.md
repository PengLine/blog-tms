- 每个页面在 DOMContentLoaded 中先调用 checkLoginStatus('admin') 校验管理员角色，再执行 TmsUI.initShell() 与 TmsPages.render('key', ...) 的双阶段初始化。
- 页面脚本分为两段：首段负责登录检查与 shell 渲染，第二段放在 <script type="text/plain" data-legacy="1"> 中以保留旧版逻辑（子菜单切换、事件绑定等）。
- 侧边栏导航通过 a 标签 href 指向 tms-*.html 并给当前页添加 .active 类名，子菜单使用 has-submenu + submenu 结构并通过 toggle('active') 控制展开。
- 列表型页面采用「统计卡片 grid + 数据表格」的两段式布局，状态列用 status.* 或 inventory-status.* / capacity-status.* 等语义化 class 区分 in_stock/low_stock/out_of_stock 等状态。
- tms-material.html 将业务数据持久化到 localStorage 键 tmsMaterials，并以 currentStock 与 minStock 比较自动推导 in_stock / low_stock / out_of_stock 状态。
