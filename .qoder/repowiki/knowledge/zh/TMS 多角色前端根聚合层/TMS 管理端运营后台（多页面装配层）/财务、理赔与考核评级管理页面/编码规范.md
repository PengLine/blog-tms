- 页面结构统一为 header + aside.sidebar + section.content 三段式布局，并通过内联 `<style>` 提供基础重置、统计卡片、列表项和响应式媒体查询。
- 侧边栏使用 `.has-submenu` + `.submenu` 结构配合 `toggle('active')` 实现可折叠的子菜单，同时维护 `href="#..." onclick="switchTab(...)"` 形式的标签切换入口。
- 业务初始化遵循 initMockXxx() → renderXxx() 的两阶段模式：先检查 localStorage 是否已有数据，若无则写入一组硬编码的模拟对象，再渲染到对应容器。
- 状态/类型文本通过本地 map 函数（getTypeText/getStatusText/getGradeText）将英文枚举映射为中文展示文案，避免在模板中散落分支判断。
- 用户交互操作以 `window.xxx = function(id) { ... }` 形式挂载到全局，供内联 `onclick="xxx('${id}')"` 直接调用，修改后重新 `localStorage.setItem` 并刷新列表。
- 页面脚本分为两段：首段用于登录校验与壳层初始化（调用 TmsUI/TmsPages），第二段包裹在 `<script type="text/plain" data-legacy="1">` 中以区分遗留业务逻辑。
