- 每个页面以相同的三栏布局结构组织：header（含 logo 与 logout-btn）、aside.sidebar（固定 250px 宽，列出 8 个业务入口）、section.content（主内容区）。
- 页面脚本统一在 DOMContentLoaded 回调中调用 checkLoginStatus('branch') 进行角色校验，并通过 displayCurrentUser() 渲染用户名。
- 侧边栏导航使用相对路径 href="branch-*.html" 链接到同级页面，并在当前页面对应 a 标签上添加 class="active" 标识高亮。
- 业务数据（如订单记录）通过 localStorage.getItem/setItem 读写 JSON 字符串，首次加载时若 key 不存在则写入默认模拟数据。
- 统计卡片采用 .stats-grid + .stat-card 网格布局，数值与标签分离为 stat-value / stat-label 两个子元素。
- 表单控件统一使用 form-group 包裹 label + input/select，筛选条件行用 form-row（CSS Grid auto-fit）排列。
