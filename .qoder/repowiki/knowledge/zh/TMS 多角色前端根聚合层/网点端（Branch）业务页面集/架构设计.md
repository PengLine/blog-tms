本模块由 8 个独立的 HTML 文件组成，每个文件对应一个网点业务子域：branch-index.html（首页/导航）、branch-collection.html（揽收）、branch-sorting.html（分拣）、branch-outbound.html（出库）、branch-inventory.html（库存与资产）、branch-service.html（服务与售后）、branch-operation.html（运营管理）、branch-system.html（系统管理）。所有页面共享同一套布局骨架——顶部 header + 左侧 sidebar 导航 + 右侧 content 区域，并通过相对链接互相跳转；侧边栏在每个页面中硬编码了完整的 8 个菜单项，当前页面对应 a 标签添加 active 类。页面样式全部内嵌在 <style> 块中，无外部 CSS 框架；图表能力通过 CDN 引入 chart.js（如 branch-operation.html），其余交互逻辑直接写在页面末尾的 <script> 块里，并依赖同目录下的 common.js 提供 checkLoginStatus('branch')、logout、displayCurrentUser 等通用函数完成登录态校验与退出。数据层使用 localStorage 持久化模拟订单记录，未调用后端 API。
